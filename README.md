# 网络工具 (Network Tool)

Windows 桌面版局域网网络工具，集 **批量 Ping**、**局域网设备发现**、**海康 SADP**、**大华 ConfigTool 协议发现** 于一身的绿色单文件程序。

> 开发者：**ysl** ｜ 邮箱：**328357351@qq.com**

## 功能

### 1. 批量 Ping
- 16×16 红绿网格，一眼看清 256 个地址的在线状态
- 单击格子弹出**长 Ping** 窗口（持续 ping、统计丢包、保存记录）
- 导出 Excel/CSV 报表；悬停显示 IP、延迟、扫描时间
- 字号随窗口自适应缩放

### 2. 设备发现
- Ping 扫描 + TCP 端口预扫描 + ARP 表 + 组播发现 + Web 指纹
- 自动识别厂商（海康/大华/ONVIF 等）与设备类型（摄像机/NVR/主机）
- 表头点击排序（IP 按数值排序），右键可直接打开设备管理网页
- 支持跨网段：填起止 IP 即可

### 3. 海康设备 (SADP)
- 逆向实现海康 SADP/HiDiscover 组播协议（239.255.255.250:37020）
- 可发现**同一层网络内任意网段**的设备，含改错 IP、未激活设备
- 列出型号、序列号、固件版本、激活状态、HTTP 端口、MAC

### 4. 大华设备
- 逆向实现大华 ConfigTool 发现协议：
  - v1：UDP 5050 广播（老固件）
  - v2：UDP 37810 DHIP/JSON 组播 239.255.255.251 + 广播（新固件）
  - 心跳被动监听（30000）
- 逐网卡发**定向广播**，多网卡/多网段都能覆盖
- 搜完自动停止（连续 8 秒无新设备），点击搜索自动刷新列表
- 「指定IP → 单播探测」支持单个/多个/整段（`192.168.1.1-254`、`192.168.1.0/24`），纯单播不发广播
- 「扫描该范围」协议单播 + 端口探测二合一

### 其它
- 多网卡支持：底部可切换收发网卡，常驻监听随网卡切换自动重启
- 常驻监听：程序一打开就监听设备主动上报，对标 ConfigTool
- 表格历史缓存、高 DPI 清晰渲染、浅色扁平界面

## 下载

直接下载仓库里的 [`网络工具.exe`](./网络工具.exe)（Windows 10/11 x64，绿色单文件，无需安装）。

## 从源码构建

```bat
pip install pyinstaller
pyinstaller --onefile --windowed --name 网络工具 ping_tool.py
```

依赖：Python 3.10+（标准库 tkinter，无第三方运行时依赖）。

## 使用提示

- 搜不到设备时先检查 **Windows 防火墙**是否放行本程序的入站 UDP（37020/3702/5050/37810/30000）
- UDP 5050 常被 Windows「连接设备平台服务 (CDPSvc)」独占，回固定 5050 端口的老固件可能漏发现，可管理员执行 `net stop CDPSvc` 临时释放
- 跨网段广播会被路由器拦截，跨网段请用「指定IP 单播探测」或「扫描该范围」
